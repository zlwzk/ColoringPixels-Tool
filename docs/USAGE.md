## 2. 安装 / 卸载

### 图形界面安装

1. 完全退出要安装的游戏。
2. 运行 `ColoringPixelsTool-Setup-vX.Y.Z.exe`。
3. 在顶部标签选择目标游戏，安装器会自动检测目录；若检测失败可点「浏览」手动选择**包含该游戏主程序**的目录。
4. 点击「一键安装」，等待进度条完成。
5. 安装完成后游戏会自动启动（可在「安装选项」里关闭）。

落地文件：

| 游戏 | 写入内容 |
| --- | --- |
| 《Coloring Pixels》 | `winhttp.dll`、`BepInEx\`（含 `plugins\ColoringPixelsTool.dll`） |
| 《涂色大师：像素梦想家》 | `PixelAssist\PixelAssist.exe`（独立文件夹，不写 BepInEx） |

### 静默安装（脚本化）

```powershell
# 静默安装《Coloring Pixels》到指定目录，不启动游戏
.\ColoringPixelsTool-Setup.exe --silent --dir="D:\Steam\steamapps\common\Coloring Pixels" --no-launch

# 给《涂色大师：像素梦想家》安装独立助手
.\ColoringPixelsTool-Setup.exe --game=pcs --silent --no-launch

# 两款游戏各装一次
.\ColoringPixelsTool-Setup.exe --all --silent --no-launch
```

退出码：`0` 成功，`1` 失败，`2` 目录无效，`3` 游戏正在运行。

### 卸载

- 重新运行安装器 → 点「卸载」；
- 在弹出的卸载对话框中可选：
  - **还原安装时备份的文件**（默认勾选）；
  - **同时移除 BepInEx 本体**：连 `winhttp.dll`、`BepInEx/` 一起删除（仅《Coloring Pixels》）。

命令行卸载：

```powershell
.\ColoringPixelsTool-Setup.exe --uninstall --remove-bepinex
```

卸载《涂色大师：像素梦想家》的助手只会删除游戏目录下的 `PixelAssist\` 文件夹，
**不会**删除 `%APPDATA%\PixelAssist` 里的区域与参数预设。

### 手动安装（不使用安装器）

《Coloring Pixels》：

1. 打开仓库的 `vendor/bepinex-x86/`，把其中**全部内容**复制到游戏目录。
2. 用 `installer/payload/doorstop_config.ini` 覆盖游戏目录下的同名文件。
3. 把 `artifacts/ColoringPixelsTool.dll` 复制到 `<游戏目录>\BepInEx\plugins\`。
4. 启动游戏。

《涂色大师：像素梦想家》：把 `dist` 包里的 `PixelAssist\` 整个文件夹复制到游戏目录即可。

## 4. 面板各页说明

进入关卡后按 <kbd>F1</kbd> 打开面板。面板按分辨率自适应缩放（可在「设置 → 面板外观」里手动指定倍数）。
顶部是两个模块：**自动完成**（替代手涂）与**人工辅助**（自己涂，但不用一直按住左键），切换后各自有独立页签。

### 4.1 自动完成

#### 首页

显示当前关卡进度、绘画计时器（开始 / 暂停 / 重置 / 同步到自动化）、自动化状态，以及「一键涂完 / 清空画布 / 拟人涂色 / 颜色高亮」四个快捷操作。

#### 涂色

| 功能 | 说明 |
| --- | --- |
| 一键涂完本关 | 立即把当前关卡所有格子涂完 |
| 涂完当前颜色 | 只涂完调色板中当前选中的颜色 |
| 清空画布 | 把当前关卡重置为未涂状态 |
| 立即保存 | 立刻写盘，避免进度丢失 |
| 重载本关 | 重新读取当前关卡的画布数据 |
| 调色板 | 点击剩余色块可快速涂完该颜色 |

页面顶部会显示画布尺寸、颜色数量与完成进度。

#### 拟人

模拟真实玩家的涂色节奏，降低「机械一键完成」的痕迹。

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| 手速 | 每秒涂多少格 | 45（5–220） |
| 笔触长度 | 一笔连续涂多少格后可能停笔 | 30（5–150） |
| 就近分块 | 路径规划分块边长，越小越局部 | 8（2–32） |
| 停笔概率 | 每笔结束后随机停笔的概率 | 0.4 |
| 手滑概率 | 偶尔涂错再回头补上 | 0（0–0.12） |
| 先涂大面积颜色 | 按剩余数量从多到少处理颜色 | 关 |
| 同步调色板高亮 | 自动切换游戏内选中的颜色 | 开 |
| 只涂当前颜色 | 仅处理当前高亮的颜色 | 关 |
| 自动保存 | 涂完后写入存档 | 开 |

算法要点：按颜色逐个处理 → 将同色格子**就近分块** → 块内**蛇形扫行**生成路径 → 按手速推进并在每「笔」后按概率停顿 → 可选手滑。整体更接近真人操作。

#### 自动化

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| 总时长分钟 | 自动化任务的总运行时间 | 30（1–480） |
| 连续涂图 | 当前图片涂完后尝试打开下一张继续 | 关 |
| 换图间隔秒 | 完成一张图后到切换下一张的等待时间 | 3（0.5–30） |
| 涂色速度预设 | 0 = 用「拟人」页速度；1 慢 / 2 中 / 3 快 | 1 |

#### 辅助（画布颜色高亮）

把**当前选中颜色**在画布上对应的格子高亮出来，方便快速定位；纯视觉辅助，不修改任何游戏数据（不改存档、不改进度）。

| 功能 | 说明 | 默认值 |
| --- | --- | --- |
| 启用颜色高亮 | 在画布上高亮当前选中颜色的格子 | 开 |
| 仅高亮未涂格子 | 已涂对的格子不再高亮 | 开 |
| 呼吸闪烁 | 高亮随时间轻微明暗变化 | 开 |
| 高亮样式 | 填充 / 描边 / 四角框 | 填充 |
| 高亮颜色 | 8 种预设色块，或用 R / G / B 滑条自选 | #FF3EA5 |
| 不透明度 | 高亮叠加的透明度 | 0.55 |

> 热键 <kbd>F6</kbd> 可随时开关高亮。高亮只在关卡内可见，并随缩放 / 平移实时贴合画布。

#### 解锁

| 功能 | 说明 |
| --- | --- |
| 解锁全部 DLC | 让所有 DLC / 奖励书籍可直接进入 |
| 免费提示 | 无视关卡设置，始终启用提示 |
| 提示强度 | 1 = 普通提示；2 = 重提示（跟随当前颜色） |
| 显示隐藏书籍 | 显示默认隐藏的书本 |
| 标记书籍完成 | 把书籍标记为已完成 |
| 解锁 Steam 成就 | 触发成就解锁 |

> 仅供单机娱乐，请自行评估使用风险。

#### 设置

| 分区 | 内容 |
| --- | --- |
| 用户资料 | 用户名、头像图片、面板背景图片；「保存资料并刷新」「打开配置文件夹」「清除背景」（卡片底部会显示等级存档所在目录，见 [6.3](#63-等级与用户资料存档)） |
| 面板外观 | 面板不透明度、面板缩放（0 = 自适应） |
| 悬浮 HUD | 显示 HUD、颜色明细、本图用时、不透明度、屏幕坐标 |
| 快捷键 | 全部热键的查看与修改（含人工辅助 F7–F12） |
| 游戏界面汉化 | 汉化开关、范围（仅设置页 / 全部界面）、自动替换中文字体、汉化字体、补充词条文件 |
| 推荐预设 | 是否在游戏设置里显示「推荐预设」按钮、按钮位置与偏移、预设文件 |
| 界面诊断 | 面板缩放相关的一键重算 / 放大 |
| 自动化与安全 | **自动绘图已解锁**（可在此重新上锁）、爱心二次确认、HUD 用时 |
| 语音交互 | 启用语音换色、识别模式（听写 / 关键词） |
| Bug 反馈与功能建议 | 反馈类型、标题、描述、联系方式、GitHub Token |
| 新手指引 | 启动时是否自动显示，以及重新打开指引 |
| 关于 | 版本号与更新公告 |

**关于「自动绘图」上锁**：「涂色 / 拟人 / 自动化」三页会把结果写进当前关卡存档，因此默认上锁。
在「解锁」页点击「解锁自动绘图」会弹出风险提示（会提示这是不可撤销的存档操作），
确认键带 **3 秒冷静期**，确认一次即长期有效；之后可在「设置 → 自动化与安全」里重新上锁。

#### 调试

进阶用途，直接读写：

- `CrossLevelStorage`：跨关卡存档字段（累计涂色、已完成数等）；
- `ClickTest`：当前关卡运行时字段（画布、颜色、进度等）。

修改前请务必先「立即保存」备份，误改可能导致存档异常。

### 4.2 人工辅助

这一模块不代替你判断颜色，而是**扫描屏幕 + 模拟鼠标**，按住左键匀速逐行扫过你框选的区域。
每一格是否涂对仍由游戏自己判定，因此进度、统计与手涂完全一致。

| 页签 | 内容 |
| --- | --- |
| 扫描 | 状态与进度、开始 / 暂停、停止、试扫本行、重新整扫、格子校准、区域概览 |
| 区域 | 拖动四个角点把矩形调成平行四边形 / 梯形；拖每条边的中点可把直边弯成弧线，贴合不规则画布 |
| 参数 | 扫描行数、鼠标速度、采样步长、行间停顿、边缘内缩、蛇形往返、按住鼠标左键、人工干预检测、开始倒计时、干预判定半径、自动停止、自动换色及换色等待 |
| 预设 | 参数预设的命名保存 / 加载 / 删除，以及「通用 / 精细小图 / 大图极速」快速模板 |
| 助手 | 引擎状态、使用说明、独立助手说明，以及打开 `%APPDATA%\PixelAssist` 配置目录 |
| 设置 | 与「自动完成 → 设置」相同 |
| 调试 | 字段页 |

标准流程：

1. <kbd>F8</kbd> 在屏幕上拖拽，框出整个画布区域；
2. <kbd>F12</kbd> 再框选其中一个格子，自动推算扫描行数与采样步长；
3. <kbd>F7</kbd> 开始，随时 <kbd>F9</kbd> 急停；<kbd>F10</kbd> 只扫当前行，<kbd>F11</kbd> 从头重扫。

> <kbd>Q</kbd> 键按住时等同于一直按住鼠标左键，手不用一直压着。

## 5. 独立助手 PixelAssist

《涂色大师：像素梦想家》为 IL2CPP，无法注入插件，因此改用独立 WinForms 助手。

用法：

1. 启动游戏并进入关卡；
2. 运行 `<游戏目录>\PixelAssist\PixelAssist.exe`；
3. <kbd>F7</kbd> 框选画布 → <kbd>F11</kbd> 校准格子 → <kbd>F6</kbd> 开始。

窗口内可调项：

| 项目 | 默认 | 范围 |
| --- | --- | --- |
| 扫描行数 | 20 | 1–400 |
| 鼠标速度 | 1400 | 200–8000 |
| 采样步长 | 4 | 1–30 |
| 行间停顿 | 100 | 0–2000 |
| 边缘内缩 | 2 | 0–20 |
| 开始倒计时 | 1200 | 0–8000 |
| 干预判定半径 | 90 | 20–400 |
| 自动停止 | 0（不自动停） | 0–600 |
| 每 N 行换色 | 0（关闭） | 0–400 |
| 换色等待 | 0 | 0–60000 |

勾选项：蛇形往返、按住鼠标左键、人工干预检测；下拉：自动换色按键（关闭 / 空格 / Tab / 1–5 / Q / E / R / F）。

覆盖层：全屏、置顶、**点击穿透**，显示区域轮廓、弯边曲线、扫描线网格、当前行高亮，以及顶部状态卡（进度、当前行、已用时间）。<kbd>F12</kbd> 或窗口按钮可开关。

配置与预设保存在 `%APPDATA%\PixelAssist\`：`Assist.region`、`Assist.settings`、`Presets\*.txt`。

### 6.3 等级与用户资料存档

等级、经验值与各项统计存在**漫游目录**，不放在游戏目录里：

```
%APPDATA%\ColoringPixelsTool\ColoringPixelsTool.Profile.json
```

之所以不放游戏目录，是因为 `BepInEx\config` 会随「覆盖安装 / 卸载插件 / 验证游戏文件完整性 /
重装游戏」一起消失，放在那儿就会出现「更新一次版本，等级从头再来」。

- 升级到本版本后，会自动把旧位置（`BepInEx\config\ColoringPixelsTool.Profile.json`）的进度迁移过来，
  并继续在旧位置留一份镜像副本作为备份。
- 同一目录下还有 `ColoringPixelsTool.Profile.json.bak`（上一份存档）与
  `ColoringPixelsTool.Profile.json.corrupt-*`（读出来怀疑损坏的存档，不会被直接删掉）。
- 只要经验值还在，等级就能反推还原：存档里 `level` 字段丢了也不会掉级。

## 8. 排错

| 现象 | 排查 |
| --- | --- |
| 按 F1 无反应 | 是否已进入关卡；检查 `BepInEx\plugins\ColoringPixelsTool.dll` 是否存在；查看 `BepInEx\LogOutput.log` |
| 「涂色 / 拟人 / 自动化」点不进去 | 三页默认上锁，先在「解锁」页解锁自动绘图 |
| 游戏启动即闪退 | 是否装错位数（插件仅支持 32 位主程序）；卸载后重装 |
| 人工辅助框选后扫不到格子 | 先用「格子校准」框一个格子推算行数与步长，再微调区域四角 |
| 独立助手没反应 | 确认助手已作为普通程序运行、游戏在前台；助手使用全局热键，被其它软件占用时需更换 |
| 安装器提示权限不足 | 用管理员身份运行 |
| 安装器提示游戏正在运行 | 关闭游戏后重试，或允许安装器结束进程 |
| 面板参数不生效 | 检查 `coloringpixels.cheatsuite.cfg` 是否被锁为只读 |
| 存档异常 | 用「调试」页前请先保存备份；必要时用游戏内备份还原 |

日志位置：

- 插件运行日志：`<游戏目录>\BepInEx\LogOutput.log`
- 安装器日志：`%TEMP%\ColoringPixelsTool-Setup.log`
