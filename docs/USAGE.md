## 1. 安装 / 卸载

### 图形界面安装

1. 完全退出《Coloring Pixels》。
2. 运行 `ColoringPixelsCheat-Setup-vX.Y.Z.exe`。
3. 安装器会自动检测游戏目录；若检测失败可点「浏览」手动选择**包含 `ColoringPixels.exe`** 的目录。
4. 点击「一键安装」，等待进度条完成。
5. 安装完成后游戏会自动启动（可在启动选项中关闭）。

### 静默安装（脚本化）

```powershell
# 指定目录、静默安装、不启动游戏
.\ColoringPixelsCheat-Setup.exe --silent --dir="D:\Steam\steamapps\common\Coloring Pixels" --no-launch
```

退出码：`0` 成功，`1` 失败，`2` 目录无效，`3` 游戏正在运行。

### 卸载

- 重新运行安装器 → 点「卸载」；
- 在弹出的卸载对话框中可选：
  - **同时移除 BepInEx 本体**：连 `winhttp.dll`、`BepInEx/` 一起删除；
  - **还原备份**：把安装时被覆盖的原文件恢复回去。

命令行卸载：

```powershell
.\ColoringPixelsCheat-Setup.exe --uninstall --remove-bepinex
```

### 手动安装（不使用安装器）

1. 打开仓库的 `vendor/bepinex-x86/`，把其中**全部内容**复制到游戏目录。
2. 用 `installer/payload/doorstop_config.ini` 覆盖游戏目录下的同名文件。
3. 把 `artifacts/ColoringPixelsCheat.dll` 复制到 `<游戏目录>\BepInEx\plugins\`。
4. 启动游戏。

## 2. 打开面板

**先进入任意关卡**，然后按 <kbd>F1</kbd>。默认热键：

| 按键 | 功能 |
| --- | --- |
| <kbd>F1</kbd> | 打开 / 关闭面板 |
| <kbd>F2</kbd> | 一键涂完当前关卡 |
| <kbd>F3</kbd> | 开始 / 停止拟人涂色 |
| <kbd>F4</kbd> | 清空当前画布 |
| <kbd>F5</kbd> | 立即保存 |
| <kbd>F6</kbd> | 开关画布颜色高亮 |

热键可在面板或配置文件中修改。

## 3. 面板各页说明

### 涂色

| 功能 | 说明 |
| --- | --- |
| 一键涂完 | 立即把当前关卡所有格子涂完 |
| 涂完当前颜色 | 只涂完调色板中当前选中的颜色 |
| 清空画布 | 把当前关卡重置为未涂状态 |
| 立即保存 | 立刻写盘，避免进度丢失 |
| 重载关卡 | 重新读取当前关卡的画布数据 |
| 调色板 | 点击色块可快速涂完该颜色 |

页面顶部会显示画布尺寸、颜色数量与完成进度。

### 拟人涂色

模拟真实玩家的涂色节奏，降低「机械一键完成」的痕迹。

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| 手速 | 每秒涂多少格 | 45（5–220） |
| 笔触长度 | 一笔连续涂多少格后可能停笔 | 30（5–150） |
| 就近分块 | 路径规划分块边长，越小越局部 | 8（2–32） |
| 停笔概率 | 每笔结束后随机停笔的概率 | 0.4 |
| 手滑概率 | 偶尔涂错再回头补上 | 0（0–0.12） |
| 先涂大面积颜色 | 按剩余数量从多到少处理颜色 | 关 |
| 同步调色板高亮 | 自动切换游戏内选中的颜色 | 开 |
| 只涂当前颜色 | 仅处理当前高亮的颜色 | 关 |
| 自动保存 | 涂完后写入存档 | 开 |

算法要点：按颜色逐个处理 → 将同色格子**就近分块** → 块内**蛇形扫行**生成路径 → 按手速推进并在每「笔」后按概率停顿 → 可选手滑。整体更接近真人操作。

### 人工辅助（画布高亮）

把**当前选中颜色**在画布上对应的格子高亮出来，方便快速定位；纯视觉辅助，不修改任何游戏数据（不改存档、不改进度）。

| 功能 | 说明 | 默认值 |
| --- | --- | --- |
| 启用颜色高亮 | 在画布上高亮当前选中颜色的格子 | 开 |
| 仅高亮未涂格子 | 已涂对的格子不再高亮 | 开 |
| 呼吸闪烁 | 高亮随时间轻微明暗变化 | 开 |
| 高亮样式 | 填充 / 描边 / 四角框 | 填充 |
| 高亮颜色 | 8 种预设色块，或用 R / G / B 滑条自选 | #FF3EA5 |
| 不透明度 | 高亮叠加的透明度 | 0.55 |

> 热键 <kbd>F6</kbd> 可随时开关高亮。高亮只在关卡内可见，并随缩放 / 平移实时贴合画布。

### 解锁

| 功能 | 说明 |
| --- | --- |
| 解锁全部 DLC | 让所有 DLC / 奖励书籍可直接进入 |
| 免费提示 | 无视关卡设置，始终启用提示 |
| 提示强度 | 1 = 普通提示；2 = 重提示（跟随当前颜色） |
| 显示隐藏书籍 | 显示默认隐藏的书本 |
| 标记书籍完成 | 把书籍标记为已完成 |
| 解锁 Steam 成就 | 触发成就解锁 |

> 仅供单机娱乐，请自行评估使用风险。

### 显示

| 功能 | 说明 |
| --- | --- |
| 显示 HUD | 屏幕上的实时进度浮层 |
| HUD 颜色明细 | 列出每种尚未涂完的颜色 |
| HUD 不透明度 | 0.25–1.0 |
| HUD_X / HUD_Y | 浮层坐标，可直接拖动或输入 |

### 字段

进阶用途，直接读写：

- `CrossLevelStorage`：跨关卡存档字段（累计涂色、已完成数等）；
- `ClickTest`：当前关卡运行时字段（画布、颜色、进度等）。

修改前请务必先「立即保存」备份，误改可能导致存档异常。

## 6. 排错

| 现象 | 排查 |
| --- | --- |
| 按 F1 无反应 | 是否已进入关卡；检查 `BepInEx\plugins\ColoringPixelsCheat.dll` 是否存在；查看 `BepInEx\LogOutput.log` |
| 游戏启动即闪退 | 是否装错位数（本插件仅支持 32 位主程序）；卸载后重装 |
| 安装器提示权限不足 | 用管理员身份运行 |
| 面板参数不生效 | 检查 `coloringpixels.cheatsuite.cfg` 是否被锁为只读 |
| 存档异常 | 用「字段」页前请先保存备份；必要时用游戏内备份还原 |

日志位置：

- 插件运行日志：`<游戏目录>\BepInEx\LogOutput.log`
- 安装器日志：`%TEMP%\ColoringPixelsCheat-Setup.log`
